# IIT Bombay Techfest '26 - Cyberpunk Landing Page

A futuristic cyberpunk-themed landing page for IIT Bombay Techfest 2026 featuring interactive sections, event showcases, a terminal console, countdown timer, and a digital registration pass generator.

## Features

- Cyberpunk UI design
- Animated hero section
- Countdown timer
- Interactive terminal console
- Event showcase cards
- Registration form
- Digital Techfest pass generation
- Responsive layout

## Project Structure

├── index.html
├── styles.css
├── script.js
└── README.md

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download all project files.
2. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
3. Open `index.html` in any modern web browser.
